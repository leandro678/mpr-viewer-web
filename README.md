# MPR Viewer Web

Sistema web para visualização de componentes MPR em 2D e 3D.

## Objetivos

- Ler arquivos MPR
- Exibir dimensões da peça
- Listar operações
- Visualizar em 2D
- Visualizar em 3D

## Tecnologias

### Frontend
- React
- TypeScript

### Backend
- Node.js

### Banco de Dados
- PostgreSQL
